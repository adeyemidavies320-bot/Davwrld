# Mr Davies — Website Design Portfolio

A responsive white and blue portfolio for Adeyemi Davies, built as a lightweight static website.

## Run locally

Run `python -m http.server 3000` in this directory, then open http://localhost:3000.

## Deploy on Vercel

Import `adeyemidavies320-bot/Davwrld`. Select **Other** as the framework. Leave the build command empty and serve the repository root. No environment variables or package installation are required.

## Content and behavior

- Detailed introduction, platform services, process, skills, FAQ and contact.
- Responsive layouts, reduced-motion support and keyboard-accessible controls.
- Original illustrative design concepts, explicitly labeled as concepts rather than client case studies.
- Contact form opens the visitor’s email app; it does not store enquiries or send automatically.
- Portrait currently references the existing public portrait in the owner's daviesss repository.

## Validation

HTML parsed, unique IDs and internal anchors checked, embedded JavaScript syntax checked using Node. Visual browser verification remains pending because the remote browser could not reach the local preview server.
